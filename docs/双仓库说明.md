# 双仓库说明

双仓库，顾名思义就是这个 repo 实际上需要两个仓库
我确实也是这么做的。

在 `v0.1.1 beta0` 之前就已经开始做了双仓库化（2605优化合集 #58）就实现了配置的独立化，自此配置文章和主站代码就互不牵扯。

但同时也增加了重新部署环境的复杂度。

## 本地环境和CI

先克隆两个仓库。

```bash
git clone https://github.com/cilxry/cilxry-corner.git
git clone https://github.com/cilxry/cilxry-markdown-pages.git
```

之后呢在运行之前，需要先将对应的文件夹软链到对于地址。
或者在CI这种一次性环境，直接移动到对于目录。

## 后续

后续会计划在config中使用选项来选择使用单仓库或者多仓库。
